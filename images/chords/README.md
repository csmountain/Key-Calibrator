# Chord Shape Images

This folder contains images of chord shapes for the Key Calibrator application.

## Naming Convention

Name your chord image files using the following format:
- `[chord-name].png` or `[chord-name].jpg`

Examples:
- `C.png` - C major chord
- `Cm.png` - C minor chord
- `C7.png` - C7 chord
- `Cdim.png` - C diminished chord
- `F#.png` - F# major chord
- `Bbm7.png` - Bb minor 7 chord

## Organization

You can organize chord images in subfolders if needed:
- `major/` - Major chords
- `minor/` - Minor chords
- `dominant/` - Dominant 7th chords
- `diminished/` - Diminished chords
- `other/` - Other chord variations

Or organize by root note:
- `C/` - All C-based chords (C, Cm, C7, Cdim, etc.)
- `D/` - All D-based chords
- etc.
